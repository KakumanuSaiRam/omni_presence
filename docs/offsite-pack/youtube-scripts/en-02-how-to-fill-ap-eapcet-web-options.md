## Hook

A good rank is a queue number. The ordered list is what turns it into a seat.

## Talking points

1. Build the list on paper: dream, realistic, safety.
2. Use last year’s closing ranks for your category and local area — not an OC screenshot.
3. Fifteen famous CSE colleges is how decent ranks go seatless. Many lists need 100+ realistic rows.
4. Never rank a campus you would refuse above one you would join.
5. Names on certificates must match the application. Verification can cancel an allotment SMS.
6. Screenshot the submitted list. Rearrange between rounds with new data.
